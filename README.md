# NNPTUD_Ngay2

## Giới thiệu / Introduction
Repository này chứa các bài tập và ví dụ cho Ngày 2 của khóa học NNPTUD.

This repository contains exercises and examples for Day 2 of the NNPTUD course.

## Nội dung / Contents

### 1. Cơ bản Python / Python Basics
- Biến và kiểu dữ liệu / Variables and Data Types
- Cấu trúc điều khiển / Control Structures
- Hàm / Functions
- Lớp và Đối tượng / Classes and Objects

### 2. Bài tập / Exercises
Các bài tập thực hành trong thư mục `exercises/`

Practice exercises in the `exercises/` directory

### 3. Ví dụ / Examples
Các ví dụ minh họa trong thư mục `examples/`

Illustrated examples in the `examples/` directory

## Cách sử dụng / How to Use

```bash
# Clone repository
git clone https://github.com/khachuynguyen0/NNPTUD_Ngay2.git
cd NNPTUD_Ngay2

# Chạy ví dụ / Run examples
python examples/hello_world.py
python examples/calculator.py

# Chạy bài tập / Run exercises
python exercises/exercise1.py
```

## Yêu cầu / Requirements
- Python 3.7 trở lên / Python 3.7 or higher
